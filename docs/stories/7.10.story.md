## Story

**As a** lojista,
**I want** ver métricas reais de vendas no meu painel (total por período e
produtos mais vendidos),
**so that** eu acompanhe meu desempenho sem depender de dado mockado.

## Acceptance Criteria

1. `AnalyticsPort.salesSummary` no adapter Supabase (hoje
   `NotImplementedError`) retorna, para o `estabelecimentoId` e `periodo`
   informados (`7d`/`30d`/`90d`/`1a`), `{periodo, totalVendasReais:
   SUM(total_pago_reais) dos pedidos entregue com entregue_em dentro do
   período, totalPedidos: COUNT(*) desses pedidos}`.
2. `AnalyticsPort.topProducts` no adapter Supabase retorna, para o mesmo
   filtro de período, a lista de produtos agregados a partir de
   `pedidos_itens` dos pedidos entregues no período — chave de
   agrupamento `produto_id` quando não-nulo, senão `nome_snapshot`
   (mesmo fallback do mock, para produtos excluídos do catálogo);
   `quantidadeTotal = SUM(quantidade)`; `totalVendidoReais =
   SUM(subtotal_reais)`; ordenado por `totalVendidoReais DESC`.
3. RLS já garante isolamento por `estabelecimento_id` — o adapter não
   reimplementa checagem de ownership além de filtrar pelo
   `estabelecimento_id` recebido.
4. Telas "Painel" e "Vendas" (já existentes) continuam funcionando sem
   alteração de código — total, contagem, gráfico de barras (derivado do
   top 7 produtos) e lista "Top produtos" refletem dados reais.
5. Período sem nenhuma venda retorna `totalVendasReais: 0, totalPedidos:
   0` e `topProducts: []` (estado vazio já tratado pela tela).
6. Testes cobrem: os 4 períodos (`7d`/`30d`/`90d`/`1a`); produto com
   `produto_id` nulo (snapshot) agrupado corretamente por
   `nome_snapshot`; período sem vendas; isolamento entre dois
   estabelecimentos; paridade de fórmula com `analytics.mock.ts` para o
   mesmo conjunto de dados de teste.

### Fórmula de referência (paridade obrigatória com o mock)

```
PERIODO_DIAS = { '7d': 7, '30d': 30, '90d': 90, '1a': 365 }
pedidos_periodo = pedidos WHERE estabelecimento_id = :id
                    AND status = 'entregue'
                    AND entregue_em >= now() - periodo_dias

salesSummary.totalVendasReais = SUM(pedidos_periodo.total_pago_reais)
salesSummary.totalPedidos     = COUNT(pedidos_periodo.*)

topProducts: agrupar pedidos_itens dos pedidos_periodo por
  (produto_id IS NOT NULL ? produto_id : nome_snapshot)
  quantidadeTotal   = SUM(quantidade)
  totalVendidoReais = SUM(subtotal_reais)
  ORDER BY totalVendidoReais DESC
```
